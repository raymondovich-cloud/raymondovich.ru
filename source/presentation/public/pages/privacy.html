Обработка персональных данных.

Информация о данных, которые передаются при отправке заявки через Telegram Mini App.

Редакция для технической проверки.

До публичного включения формы владелец должен дополнить сведения об операторе и проверить правовые основания и формулировки уведомления с учётом применимой юрисдикции.

Отдельно необходимо проверить применимость требований 152-ФЗ: проект Supabase сейчас размещён в Frankfurt (EU Central), а данные заявок также передаются в Telegram через Bot API. Если обрабатываются персональные данные граждан РФ, до запуска требуется юридически подтвердить допустимость первичного хранения и трансграничной передачи либо изменить схему размещения данных.

1. Кто обрабатывает данные

Оператором выступает владелец сайта Raymondovich.ru. Полное юридическое наименование или ФИО оператора, адрес и необходимые регистрационные сведения должны быть указаны владельцем до публичного запуска формы.

2. Какие данные обрабатываются

  • имя, которое пользователь указывает самостоятельно;
  • текст обращения;
  • Telegram ID и, если доступен, username;
  • язык интерфейса Telegram;
  • метка источника и необязательная метка кампании из параметра ссылки (для прямых ссылок Telegram это может быть неподписанная техническая метка);
  • техническая подсказка о платформе Telegram-клиента.

Форма не запрашивает номер телефона, адрес электронной почты, документы или платёжные данные.

3. Для чего используются данные

Данные используются для получения, рассмотрения и ответа на обращение, а также для определения указанной в ссылке метки источника. Метка источника не подтверждает фактическое место, где пользователь увидел ссылку.

4. Где обрабатываются и кому передаются данные

Заявки хранятся в базе данных Supabase проекта Raymondovich, размещённого в регионе EU Central (Frankfurt). Уведомление о новой заявке передаётся владельцу в Telegram через Telegram Bot API. Доступ к содержимому заявки ограничен серверной частью и владельцем платформы.

5. Срок хранения

Заявка хранится до закрытия. После закрытия она удаляется по автоматическому расписанию не позднее чем через 90 дней после даты закрытия (ежедневная очистка может выполняться с задержкой до 24 часов).

6. Вопросы и запросы

Для вопросов об обращении или запросов, связанных с данными, можно написать через бота Raymondovich. Контактный канал и порядок обработки запросов должны быть окончательно подтверждены оператором до публичного запуска.
