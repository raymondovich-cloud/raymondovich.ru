# Business modules

Модули изолируют бизнес-возможности и владеют своими доменными моделями.

- identity — идентичность, сессия, роли и разрешения;
- public — публичная презентация и каталог;
- owner — сценарии владельца;
- partner-projects — совместные проекты Raymondovich;
- external-projects — допущенные сторонние проекты;
- projects — общие понятия проекта, только если они действительно общие;
- products — продукты и коммерческие предложения;
- portfolio — сводный портфель;
- settings — настройки платформы.

Модули взаимодействуют через публичные API и контракты. Нельзя импортировать внутренние файлы соседнего модуля.
