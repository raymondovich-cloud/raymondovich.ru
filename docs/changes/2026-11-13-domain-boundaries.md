# Изменения — правила доменного владения и междоменных связей

**Дата:** 2026-11-13  
**Версия:** 1.0

## Изменено

- Обновлён `docs/agent.md` с версии 1.0 до 1.1.
- Зафиксированы пять глобальных доменов: profile, ideas, team, tools, projects.
- Установлено правило: предметные сущности и бизнес-логика каждого раздела принадлежат его каталогу в `source/domain/`.
- Определён отдельный слой `source/ecosystem/` для моделей и правил связей между несколькими глобальными доменами.
- Зафиксированы границы междоменного слоя и запрет дублирования доменной логики.
- Добавлен процесс обоснования исключений.
- Существующий `source/domain/control-center/` отмечен как историческая архитектурная неоднозначность, требующая отдельного решения; автоматическое перемещение не выполнялось.

## Ограничения

- Исходный код и структуру каталогов не изменяли.
- Миграции базы данных и API не создавали.
