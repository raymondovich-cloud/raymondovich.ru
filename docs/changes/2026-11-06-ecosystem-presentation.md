# Изменение публичной презентации экосистемы

**Дата:** 2026-11-06  
**Раздел:** Public / System Introduction  
**Статус:** реализовано в исходном коде; визуальная проверка в Safari ещё не проведена.

## Что изменено

- Сценарий «Знакомство с системой» заменён на единую автоматическую презентацию длительностью 45 секунд.
- Добавлена сцена с центральным брендом и четырьмя направлениями экосистемы.
- Система управления проектом выделена оранжевым акцентом и более выраженной связью с центром.
- Добавлены собственные продукты LIFE GAME и AI-SISTEM с текстовыми статусами.
- Добавлена внутренняя орбита системы управления и четыре модуля: бухгалтерия, подключённые сервисы, маркетинг и статистика.
- Добавлен отдельный акцент на партнёрском направлении и блоке «Стать партнёром».
- Добавлена связь с кабинетом RAYMONDOVICH | PRIVATE.
- В финале появляется CTA «Обсудить партнёрство» с существующим контактным каналом.
- Добавлены пауза, продолжение, перезапуск, пропуск к финалу и корректная остановка таймера при закрытии диалога.
- Скорость орбит установлена в 90 секунд для внешней и 110 секунд для внутренней орбиты в обратном направлении.
- CSS паттерн остаётся в Design System Core; JS управляет только временными состояниями сцены.

## Проверки и ограничения

- Проверена связность временных этапов: 0, 3, 6, 12, 20, 30, 36, 41 и 45 секунд.
- Проверено наличие контролов управления и финального CTA в разметке.
- Учтено системное предпочтение `prefers-reduced-motion`: непрерывное вращение отключается.
- Фактический визуальный просмотр в мобильном Safari и на опубликованном сайте не выполнен. Позиционирование и читаемость элементов требуют проверки на реальном экране.
