# 2026-11-12 — Расположение кнопки избранного в списке проектов

## Цель
Убрать отдельную визуальную подложку у звёздочки избранного в реестре проектов и визуально встроить управление избранным в карточку проекта.

## Изменения
- Для карточек раздела «В фокусе» звёздочка расположена внутри рамки карточки в правом верхнем углу.
- Для строк раздела «Остальные» звёздочка расположена справа на поверхности самой строки, без отдельного фона и отдельной рамки.
- Добавлен внутренний отступ карточек под кнопку, чтобы звёздочка не перекрывала название, описание и метаданные.
- Состояния активного избранного, доступность кнопки и обработчик переключения сохранены.
- Кнопка избранного внутри открытого проекта и на других экранах не изменялась.

## Затронутые файлы
- `source/presentation/public/scripts/projects.js`
- `source/design-system/patterns/favorites.css`
- `index.html` — обновлена версия URL таблицы стилей для сброса клиентского кеша.

## Проверки
- Проверить синтаксис изменённого JavaScript.
- Проверить отображение «В фокусе» и «Остальные» на мобильном Safari и широком экране.
- Проверить добавление и удаление проекта из избранного.

## Ограничения
В этой среде не выполняется визуальный браузерный тест. После публикации требуется проверить интерфейс на реальном устройстве.
