## Уточнение требований к темам интерфейса

- По решению владельца светлая и тёмная темы имеют равный приоритет.
- Обе темы должны проектироваться как полноценные самостоятельные оформления, а не как основная тема и упрощённая адаптация.
- Для каждой темы отдельно проверяются поверхности, текст, разделители, состояния компонентов, контраст и материалы Liquid Glass.
- Обновлён `docs/architecture/authenticated-ui-standard.md` до редакции 0.2.

## Глобальный поиск авторизованного пространства

- В авторизованную оболочку и приветственный экран добавлена единая поисковая панель без постоянной кнопки.
- Для вызова реализован Pull Down: жест начинается только в верхней области экрана при нулевой прокрутке; порог первого среза — 72 CSS px. Добавлены состояния подсказки «Потяните ещё немного» / «Отпустите для поиска», анимация панели и поддержка reduced motion.
- Поиск доступен во всех экранах авторизованной оболочки. Дополнительно поддерживаются Ctrl/Cmd+K и клавиша / на устройствах с клавиатурой.
- Добавлен application-level поиск по проектам, идеям, инструментам, ресурсам, связям сервисов и ресурсов с проектами, а также по статическим пунктам доступных разделов.
- Результаты сгруппированы по источникам. Переходы к идеям и проектам используют существующие маршруты и вложенные экраны RaymondovichNavigation.
- Запросы выполняются через отдельный Supabase repository с текущей сессией пользователя. Существующие RLS-политики остаются границей доступа; миграции БД, политики, роли и grants не менялись.
- Не запрашиваются URL ресурсов, внешние идентификаторы и свободные заметки-подтверждения. Секреты не должны храниться в индексируемых описаниях.
- Добавлена архитектурная документация `docs/architecture/global-search-architecture.md`. В ней зафиксированы границы первого среза и лимит до 8 результатов на каждый источник.
- Бухгалтерия, маркетинг и аналитика пока не содержат реализованных поисковых записей: соответствующие модули находятся в состоянии not_configured и будут подключены после появления реальных источников.

### Проверки и ограничения

- Выполнен статический разбор синтаксиса четырёх изменённых JavaScript-модулей; проверены подключение CSS, баланс CSS-блоков и отсутствие прямого управления стилями из JavaScript.
- Build/lint, автоматические тесты, интеграционные запросы к Supabase, browser rendering, iPhone Safari и Telegram Mini App не запускались.
- Порог 72 CSS px является фиксированным начальным значением. Safari не предоставляет приложению точное расстояние нативного Pull to Refresh, поэтому нельзя утверждать, что это измеренная половина нативного порога.
- Поиск ограничен 8 результатами на источник и не является полнотекстовым индексом. Для больших наборов данных потребуется отдельное решение по полнотекстовому поиску и пагинации.


## Исправление перехвата Pull Down в iOS Safari

- Обработчики жеста перенесены с корня приложения на `document` в capture-фазе. Начальное касание по-прежнему принимается только внутри авторизованного корня.
- Нативное обновление страницы теперь отменяется на раннем этапе подтверждённого движения вниз (свыше 2 CSS px), до появления подсказки и до порога открытия поиска. Обработчик `touchmove` остаётся non-passive, проверяется `event.cancelable`.
- Архитектурная документация глобального поиска обновлена до версии 1.1.

### Проверки и ограничения
- Проверена точечная замена обработчиков и сохранение условий: верх страницы, верхняя зона касания, одиночный палец, исключение интерактивных элементов, игнорирование горизонтального движения и порог открытия 72 CSS px.
- iPhone Safari, Telegram Mini App и реальный нативный Pull to Refresh после изменения не проверялись. Нельзя утверждать, что проблема устранена до проверки на устройстве.
