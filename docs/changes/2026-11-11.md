- Нативное обновление страницы теперь отменяется на раннем этапе подтверждённого движения вниз (свыше 2 CSS px), до появления подсказки и до порога открытия поиска. Обработчик `touchmove` остаётся non-passive, проверяется `event.cancelable`.
- Архитектурная документация глобального поиска обновлена до версии 1.1.

- Уточнён приоритет типографики заголовка Control Center относительно общих стилей h1; верхний отступ и ритм заголовка теперь задаются его компонентным правилом.

- Исправлено назначение состояния push-screen самому scroll-контейнеру: это состояние управляет скрытием нижней навигации и переходом вложенного экрана. Ранее класс назначался только оболочке, поэтому нижняя панель оставалась видимой.

- Скрытие нижней навигации вложенных экранов переведено на явный класс оболочки вместо `:has()`, чтобы не зависеть от поддержки relational selector в WebView.

- На узких экранах до 360px уменьшен только размер подписи элементов нижней навигации, чтобы название «Инструменты» не обрезалось. Горизонтальный overflow на ширине 320px не обнаружен.

- Экран настроек перестроен по трём секциям эталона: «Оформление», «Пользовательские данные», «Конфиденциальность». E-mail и пароль объединены в одну карточку; существующие form hooks, обработчики PIN/lock/signout и валидация сохранены. Заголовок экрана приведён к «Настройки».

- Свечение активной вкладки переведено на существующий семантический токен `--rv3-accent-glow`, чтобы не дублировать цветовое значение.


## Этап 7. Временное отключение PIN-защиты

- Отключён клиентский PIN-gate в production и тестовой ветке: убраны блокирующий класс документа, подключение PIN stylesheet и запуск PIN-модуля.
- В настройках вместо PIN/блокировки оставлено управление сеансом — выход из аккаунта.
- Основная авторизация Supabase Auth, роли, права доступа и серверные проверки не изменялись.
- Edge Function `pin-auth`, таблицы и сохранённые PIN-данные не удалялись; их можно вернуть отдельным этапом.
- Изменения внесены отдельно в ветку `ui/prototype-v3-full-parity`; данные Supabase не изменялись.
- Ограничение: отключение PIN снимает дополнительную блокировку приложения на устройстве; защита зависит от основной авторизации Supabase Auth.
