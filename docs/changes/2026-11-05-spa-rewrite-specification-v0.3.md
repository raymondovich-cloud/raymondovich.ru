# Изменения архитектурной спецификации — 05.11.2026

**Документ:** `docs/architecture/spa-rewrite-specification.md`  
**Редакция:** draft 0.3  
**Рабочая ветка:** `architecture/spa-rewrite-2026-11-05`

## Зафиксировано

- Утверждена целевая модель модульного монолита с Clean Architecture и DDD.
- Функциональные области организуются как самостоятельные модули с внутренними слоями по необходимости.
- Каждый модуль обязан предоставлять ограниченный публичный API.
- Закреплён строгий запрет: модуль не имеет права обращаться к внутренним файлам или внутренним реализациям другого модуля. Межмодульное взаимодействие выполняется только через публичный API или отдельно определённый общий application-контракт.
- App Composition Root отвечает за сборку зависимостей, но не за бизнес-логику.
- Разделены обязанности Router, Application Layer, локальных Module Controllers/Coordinators, Infrastructure и Design System.
- Закреплены правила для Core/Shared и запрет на универсальные каталоги-свалки.
- Добавлена предварительная концептуальная структура каталогов; она не является окончательным деревом и будет уточнена после инвентаризации.
- Зафиксирована необходимость автоматизировать проверку архитектурных границ после выбора инструментального стека.

## Проверки

- Перед изменениями проверен HEAD рабочей ветки и совпадение с ожидаемым commit.
- Обновлённый документ и changelog добавлены только в рабочую ветку.
- Runtime, функциональные и hosting-тесты не выполнялись: изменения касаются архитектурной документации.
