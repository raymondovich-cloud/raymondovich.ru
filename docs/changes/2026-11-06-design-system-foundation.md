# Основа Design System

- Зафиксировано разделение Design System на общий Design System Core и закрытый Design System Workspace.
- Core размещается в `source/design/` и является общей возможностью платформы для всех четырёх пользовательских пространств.
- Workspace относится к Owner Control Center и предназначен для просмотра, проверки и документирования фактических токенов и компонентов.
- Зафиксированы состав системы: Tokens, Foundations, Components, Patterns и Layouts.
- Зафиксированы требования: отдельные CSS-файлы, отсутствие CSS-in-JS, единый источник токенов, доступность, адаптивность и отсутствие бизнес-/инфраструктурной логики в компонентах.
- Workspace на первом этапе не редактирует production-токены напрямую.
- Не создавались runtime-компоненты и не изменялись публичный сайт, маршруты, авторизация, Supabase или deployment.
- Технологические детали реализации оставлены для отдельных ADR.
