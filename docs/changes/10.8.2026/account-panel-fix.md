# Исправление открытия панели аккаунта

<!-- version 1.0 -->

Дата: 10.10.2026, Москва

## Изменено

- Обновлён `app.html` до версии 1.2.
- Добавлено версионирование URL CSS и JavaScript-ресурсов для принудительного обновления браузерного кэша.
- Версия JavaScript-ресурса зафиксирована как 1.4.

## Причина

Шестерёнка отображалась, но обработчик открытия панели аккаунта мог использовать закэшированную версию модуля после деплоя.

## Результат

При следующей загрузке `app.html` браузер получает актуальную версию `app-page.js`, содержащую обработчик открытия панели аккаунта.

## План

- Проверить открытие панели на опубликованном `raymondovich.ru`.
