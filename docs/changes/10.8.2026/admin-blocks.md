# Изменения

## 08.10.2026

### Административные блоки
- Обновлён состав блоков закрытой административной области Raymondovich.
- Добавлены блоки: «Продукты», «Маркетинг», «Стратегия», «Идеи», «Аналитика продуктов», «Документация».
- Удалён прежний блок «Система».
- Блок «Аналитика» переименован в «Аналитика продуктов».
- Добавлен отдельный административный блок «Идеи» для приватных идей и стратегических мыслей.
- Административные блоки отсортированы по убыванию количества букв в названии.

### Пользовательский профиль
- Убраны email и кнопка «Выйти» из верхней части панели.
- Добавлена кнопка-шестерёнка и подпись «Пользователь».
- Добавлена компактная панель профиля пользователя.
- В панели отображаются имя, email, дата регистрации и состояние аккаунта.
- Кнопка «Выйти» перенесена внутрь панели пользователя.
- Добавлено закрытие панели по кнопке, клику вне панели и клавише Escape.
