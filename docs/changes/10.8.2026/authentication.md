# Изменения

## 08.10.2026

### Авторизация и регистрация
- Создан отдельный Supabase-проект Raymondovich.
- Подключён Supabase Auth для email/password.
- Добавлена регистрация пользователей.
- Добавлен вход и выход из аккаунта.
- Добавлен пользовательский профиль с RLS.
- Роль пользователя читается только из app_metadata JWT.
- Роль по умолчанию — user.
- Административная роль не назначается клиентским кодом.
- Временная авторизация, ранее указывавшая на backend LifeGame, заменена на отдельный backend Raymondovich.

### Разделение авторизации и регистрации
- Страница `auth.html` теперь содержит только Email и Пароль.
- Поле имени полностью удалено из HTML страницы авторизации.
- Регистрация перенесена на отдельную страницу `register.html`.
- На странице регистрации используются Имя, Email и Пароль.
- Клиентская логика входа и регистрации разделена на `auth-page.js` и `register-page.js`.
- Переходы между страницами выполняются обычными ссылками без переключения режимов одной формы.

Время: после 02:00 (Москва).

### Отступ и выравнивание ссылок авторизации
- Увеличен вертикальный отступ между основной кнопкой и ссылкой перехода между авторизацией и регистрацией.
- Ссылки «Создать аккаунт» и «У меня уже есть аккаунт» выровнены по центру.

Время: после 02:00 (Москва).

### Callback подтверждения email
- Добавлена отдельная страница `auth-callback.html` для обработки перехода из письма Supabase.
- Добавлен `callback-page.js`, который обменивает authorization code на пользовательскую сессию.
- Регистрация теперь явно использует `https://raymondovich.ru/auth-callback.html` как `emailRedirectTo`.
- После успешного подтверждения пользователь автоматически перенаправляется в `app.html`.
- При недействительной или просроченной ссылке вместо пустой страницы показывается понятное сообщение об ошибке.

Время: после 02:00 (Москва).
