# Изменения

## 08.10.2026

### Авторизация и регистрация
- Создан отдельный Supabase-проект Raymondovich.
- Подключён Supabase Auth для email/password.
- Добавлена регистрация пользователей.
- Добавлен вход и выход из аккаунта.
- Добавлен пользовательский профиль с RLS.
- Роль пользователя читается только из app_metadata JWT.
- Роль по умолчанию — user.
- Административная роль не назначается клиентским кодом.
- Временная авторизация, ранее указывавшая на backend LifeGame, заменена на отдельный backend Raymondovich.

### Изменение формы авторизации
- Имя оставлено только в форме регистрации.
- Авторизация теперь использует только Email и Пароль.
- Изменена клиентская логика формы без изменений Supabase Auth и структуры профиля.
