# Changelog — public SPA routing

**Дата:** 2026-11-06  
**Репозиторий:** raymondovich.ru  
**Ветка:** main

## Изменения
- Главная страница больше не содержит каталог продуктов.
- Разделы Public вынесены в отдельные SPA-представления: главная, продукты, сотрудничество, шаги партнёрства, FAQ и контакты.
- Добавлена маршрутизация через History URL fragment: `/#/products`, `/#/cooperation`, `/#/steps`, `/#/faq`, `/#/contact`.
- Все переходы из бокового меню и верхней навигации открывают самостоятельное представление без полной перезагрузки.
- Прямое открытие ссылки, обновление страницы, кнопки Back/Forward браузера поддерживаются hash-маршрутизацией.
- Используется один `index.html`; отдельные HTML-файлы страниц не создаются.
- Для каждой страницы обновляются title и meta description.
- Активный раздел навигации синхронизируется с URL.

## Техническое решение
GitHub Pages не предоставляет штатные серверные SPA-rewrites для произвольных чистых путей. Поэтому использованы hash-маршруты: адреса вида `/#/products`. Они позволяют открывать конкретное представление напрямую и обновлять страницу без дополнительных HTML-файлов или 404-rewrite-костылей.

## Вне объёма
- Создание отдельных HTML-файлов.
- Перенос платформы на другой хостинг или внедрение серверного rewrite.
- Реализация профиля, настроек и защищённой авторизации.
