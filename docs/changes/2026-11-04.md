# Изменения — 4 ноября 2026

## Раздел «Идеи»: единая интерактивная карточка
- Убраны встроенные плашки планирования и наборы кнопок действий из рабочего списка.
- Обычное нажатие по карточке открывает подробности идеи с редактированием названия, описания, цели, экономики, бизнес-модели и дополнительных данных.
- Длительное нажатие (550 мс) открывает меню действий: запуск, изменение статуса рассмотрения, приоритет, архивирование и удаление.
- Для архивированных идей доступны восстановление и удаление.
- Для идей, переданных в проекты, удерживание открывает меню управления связанным проектом.
- Добавлена клавиатурная активация карточек и подавление случайного открытия подробностей после long-press.
- Данные и схема Supabase не менялись.

## Проверка
- Проверены статические изменения и согласованность версий ресурсов (4.13).
- Требуется пользовательская проверка сценариев в авторизованной сессии Safari на iPhone: открытие, редактирование/сохранение, удерживание, запуск и архивирование.
