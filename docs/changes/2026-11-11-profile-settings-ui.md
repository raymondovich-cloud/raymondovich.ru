# 2026-11-11 — Настройки и конфиденциальность по prototype v3

- Экран «Настройки» приведён к структуре эталона: «Оформление», «Пользовательские данные», «Конфиденциальность».
- В пользовательские данные добавлены строки «Логин», «Почта», «Пароль» и «PIN-код». Почта отображает текущий адрес авторизованного пользователя; логин берётся из существующих user metadata и не выдумывается; PIN отображается как «Не настроен».
- Секреты вынесены в отдельный вложенный экран по маршруту `#authorization/profile-secrets`. Экран содержит честное пустое состояние: защищённое хранилище ещё не подключено, тестовые секреты и статусы не создаются.
- Для логина, почты, пароля, PIN-кода и добавления секрета подготовлены UI bottom-sheet диалоги. Сохранение намеренно не подключено: введённые значения не отправляются и не сохраняются.
- Существующий переключатель тёмной темы сохранён и продолжает работать через текущий механизм темы.
- Удалены прежние формы изменения почты и пароля из экрана настроек, чтобы на этом этапе не смешивать UI-прототип с действующими операциями Supabase Auth.
- Добавлен маршрут экрана секретов в авторизованную навигацию. Для всех вложенных экранов продолжает использоваться общая кнопка возврата оболочки.
- Изменены: `profile.js`, `authenticated-app-shell.js`, `prototype-v3-parity.css` и этот журнал.

## Границы и безопасность

- Изменения выполнены только в `ui/prototype-v3-full-parity` / PR #26.
- `main`, Production frontend, Supabase, PIN-данные, реальные ключи/токены, DNS и пользовательские данные не изменялись.
- Никакие реальные секреты не добавлялись и не отображались.
- Подключение операций изменения логина/e-mail/пароля/PIN и защищённого хранилища секретов оставлено на отдельный следующий этап.

## Проверки

- Статически проверено наличие переключателя темы, всех четырёх пользовательских строк, экрана секретов и маршрута.
- Проверено, что прежние обработчики изменения e-mail/пароля больше не импортируются и не вызываются из настроек.
- Проверен баланс CSS-блоков.
- Браузерная сборка, визуальный рендеринг, iPhone Safari и Telegram WebView для этого изменения пока не подтверждены.
