# Изменение ADR-001 — фиксация решений владельца

- **Дата:** 05.11.2026
- **Документ:** `docs/architecture/adr-001-ideas-projects-lifecycle.md`
- **Ветка:** `docs/adr-001-ideas-projects`

## Зафиксировано

- Утверждена модель B: отдельные Idea и Project со связью происхождения.
- Одна Idea может породить максимум один Project.
- Project разрешено создавать без исходной Idea.
- При запуске обязателен неизменяемый snapshot исходных данных Idea.
- После запуска Idea получает статус `launched`; изменения Idea не синхронизируются с Project.
- Физическое удаление Project запрещено как обычная операция. Предусмотрена корзина, многоэтапное подтверждение и повторная серверная аутентификация.
- Проект можно восстановить в течение срока, который будет определён отдельно. Автоматическое физическое удаление после истечения срока пока не разрешено.
- Статус `rejected` не вводится; архивирование Idea обратимо.
- Финансовые значения включают сумму, валюту, период и тип показателя.
- Зафиксировано сквозное требование отдельной архитектурной области `memory`; её границы будут спроектированы отдельно.

## Границы

Изменены только архитектурные документы. Код, БД, миграции, UI, маршруты и production не затрагивались. Документ остаётся в отдельной ветке и не опубликован в `main`.
