# Changelog — Motion System and orbital introduction

**Дата:** 2026-11-06  
**Репозиторий:** raymondovich.ru  
**Ветка:** main

## Design System Core
- Добавлены канонические motion-токены.
- Добавлен foundation для системного `prefers-reduced-motion`.
- Добавлен повторно используемый паттерн орбитального знакомства с системой.
- Документация Design System Core дополнена ссылкой на Motion System.

## Public homepage
- CTA «Изучить экосистему» заменён на «Знакомство с системой».
- Добавлен управляемый модальный сценарий с тремя направлениями экосистемы.
- Добавлены переходы вперёд/назад, пропуск, закрытие и переход к каталогу после завершения.
- Анимация не переключает смысловые шаги автоматически.
- Орбитальная схема и переходы используют токены Design System Core.
- Добавлена адаптация для мобильных экранов и reduced motion.

## Ограничения
- Остальные маршруты и бизнес-логика не изменялись.
- Авторизация, backend и внешние библиотеки не добавлялись.
