# Избранное — 2026-11-12

## Согласованное решение

- Избранное — персональная связь пользователя с проектом или идеей, а не новый статус.
- Проект остаётся в «Проекты → В работе» и дополнительно появляется в «Проекты → В фокусе».
- Идея остаётся в основном разделе и дополнительно появляется в «Идеи → В фокусе».
- Оба типа объектов отображаются в едином «Профиль → Избранное».
- Снятие звезды синхронно убирает объект из соответствующих представлений, не удаляя сам объект.
- Запись избранного сохраняется при перемещении объекта в корзину; объект временно скрывается из активных представлений.
- Восстановление из корзины возвращает объект с прежней отметкой избранного.
- Окончательное удаление удаляет связь избранного через FK cascade.
- Текущая граница Projects и Ideas остаётся admin-only; партнёрские полномочия не расширяются.
