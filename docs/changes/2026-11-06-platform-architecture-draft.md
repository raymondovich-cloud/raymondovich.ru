# Архитектура платформы — Draft 1.0

**Дата:** 06.11.2026  
**Ветка:** `architecture/foundation-2026-11-06`

## Изменения

- Добавлена проектная спецификация целевой архитектуры Raymondovich.ru.
- Зафиксирована единая SPA-точка входа через корневой `index.html`.
- Описана целевая структура `source/` с семью бизнес-модулями.
- Определены обязанности слоёв Domain, Application, Infrastructure и Presentation.
- Зафиксированы четыре пользовательских пространства и централизованная маршрутизация.
- Описаны правила зависимостей, владения состоянием, межмодульных контрактов, обработки ошибок и восстановления.
- Зафиксированы требования безопасности, тестирования и документации.
- Отдельно перечислены решения, требующие ADR; неподтверждённые технологии не объявлены утверждёнными.

## Границы изменения

- Изменения внесены только в архитектурную ветку.
- `main` не изменялась.
- Исходный `index.html` и `CNAME` не изменялись.
- Код приложения, авторизация, база данных и production-инфраструктура не создавались и не изменялись.
- Документ имеет статус Draft 1.0 и ожидает утверждения владельцем.
