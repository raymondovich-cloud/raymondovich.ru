# 2026-11-12 — Диагностика загрузки рабочего пространства после входа

## Контекст
После успешного входа Supabase Auth пользователь получал сообщение, что рабочее пространство не загрузилось. Повторная попытка визуально не давала результата, а интерфейс скрывал исходную ошибку импорта/инициализации.

## Изменения
- Добавлено явное состояние загрузки рабочего пространства после подтверждения сессии.
- При ошибке загрузки интерфейс показывает имя и сообщение исключения в раскрываемом блоке «Подробности ошибки».
- Повторная попытка выполняет импорт модуля рабочего пространства с новым URL-параметром. Это обходит кеширование браузером неуспешной ESM-загрузки для прежнего URL.
- Добавлена защита от устаревших параллельных попыток: результат предыдущей попытки не должен перезаписать более новую.
- Сохранена возможность выйти из аккаунта при ошибке загрузки.

## Границы
- Supabase Auth, таблицы, RLS, ключи и секреты не изменялись.
- Это диагностическое исправление поведения клиента; оно само по себе не доказывает устранение первопричины ошибки импорта/инициализации.
- После публикации нужно получить точный текст ошибки из блока «Подробности ошибки» и устранить первопричину, если она останется.

## Проверки
- Проверить успешный вход и загрузку личного кабинета.
- При воспроизведении ошибки проверить, что блок подробностей содержит диагностическое сообщение.
- Проверить, что повторная попытка показывает состояние загрузки и запускает новый импорт.
- Проверить выход из аккаунта.
