# Изменения — Brand Identity и Color System

**Дата:** 2026-11-06  
**Репозиторий:** raymondovich-cloud/raymondovich.ru  
**Ветка:** main

## Изменено
- Утверждено базовое направление Brand Identity: светлая, тёмная и системная темы.
- Подтверждён оранжевый фирменный акцент.
- Подтверждён технологичный минимализм с выразительными градиентами.
- Обновлён статус Brand Identity до версии 1.0.

## Добавлено
- Создана спецификация Color System Foundation.
- Определено разделение primitive, semantic и component tokens.
- Зафиксированы правила разрешения системной темы и требования доступности WCAG 2.2 AA.

## Ограничения
- Конкретные цвета и градиенты пока не утверждены.
- Runtime, CSS, публичный интерфейс и production-настройки не изменялись.
