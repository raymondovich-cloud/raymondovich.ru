# Разведение звёздочки и стрелки в компактных строках проектов

- **Дата:** 2026-11-12
- **Изменение:** в разделе «Проекты» → «Остальные» звёздочка избранного закреплена справа сверху, а стрелка открытия проекта — справа снизу.
- **Затронутые файлы:**
  - `source/design-system/patterns/favorites.css`
  - `index.html`
- **Реализация:** компактная строка проекта получила дополнительное нижнее пространство; стрелка позиционируется в нижнем правом углу карточки, звёздочка — в верхнем правом. Правила адаптированы для мобильной ширины. Поведение избранного и навигация не изменяются.
- **Проверки:** проверена структура HTML-компонента и существующие CSS-селекторы по исходникам; автоматические браузерные и визуальные проверки не запускались.
- **Ограничения:** требуется визуальная проверка в Safari на iPhone после публикации.
- **Согласование:** владелец явно разрешил публикацию изменения в `main` и Production.
