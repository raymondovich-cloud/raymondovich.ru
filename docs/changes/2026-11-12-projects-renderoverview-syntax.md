# 2026-11-12 — Исправление синтаксической ошибки в навигации проектов

## Причина
В обработчике перехода на экран обзора проекта использовался `await renderOverview(...)` внутри callback-функции `.then(...)`, которая не была объявлена как `async`. Это приводило к SyntaxError при разборе всего модуля `projects.js` и блокировало загрузку рабочего пространства.

## Исправление
- Callback `.then(...)` объявлен асинхронным (`async`), поэтому ожидание `renderOverview` теперь синтаксически допустимо.
- Логика проверки актуального маршрута и идентификатора проекта сохранена.

## Проверки
- Проверить синтаксическую загрузку модуля проектов.
- Войти в аккаунт и открыть «Проекты».
- Открыть конкретный проект и проверить отображение обзора.
- Перейти в модули проекта и вернуться к обзору.

## Дополнительное восстановление авторизации

- Для регистрации и входа добавлена обработка кодов Supabase Auth: некорректный адрес, отключённая регистрация, слишком частые запросы и ошибки сети.
- Ошибка чтения сохранённой сессии больше не остаётся незаметной: пользователь получает понятное сообщение, а техническая ошибка записывается в консоль.
- Серверная модель ролей, таблицы, RLS и существующие аккаунты не изменялись.

## Автоматическая проверка

- Добавлена GitHub Actions-проверка синтаксиса всех JavaScript-файлов в `source/` на Node.js 22.
- Проверка запускается для pull request и push, чтобы синтаксическая ошибка в любом модуле не проходила незамеченной.
