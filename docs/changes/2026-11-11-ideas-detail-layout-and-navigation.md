# 2026-11-11 — Исправления экрана идеи и возврата в реестр

- Устранён источник вложенной карточной рамки: экран Идей больше не получает общий класс `.owner-console`, который предназначен для визуальной оболочки центра управления. Сохранён только структурный класс `.owner-console-workspace`; его нейтральное оформление уже задано для workspace в Design System.
- Детальный экран использует нейтральный контейнер `.ideas-detail-content`, а не прежний `.ideas-detail`, на который распространялись карточные стили.
- Описание идеи принудительно отображается целиком: автоматическая высота, перенос длинных слов и строк, сохранение переводов строк; сняты ограничения обрезки.
- Краткое описание в строках реестра может занимать до двух строк вместо одной обрезанной строки.
- Повторное нажатие активной вкладки «Идеи» синхронно инициирует сброс экрана через отдельное событие модуля; `showRegistry()` напрямую возвращает реестр даже если маршрутизатор не публикует повторное состояние текущего маршрута.
- Изменения затрагивают только интерфейс и навигацию. Данные, права и backend не изменялись.
- Работа выполнена в тестовой ветке `ui/prototype-v3-full-parity` / PR #26. `main`, Production и Supabase не затрагивались.

## Проверки
- Статически проверено, что корневой workspace Идей больше не несёт общий класс `.owner-console`; сохраняется `.owner-console-workspace` и существующие селекторы навигации/режима подробностей.
- Проверены нейтральный класс содержимого идеи, обработчик явного сброса в реестр и правила переноса описания.
- Требуется подтвердить Preview в Safari на устройстве. Визуальная проверка на реальном iPhone со стороны разработки недоступна.
