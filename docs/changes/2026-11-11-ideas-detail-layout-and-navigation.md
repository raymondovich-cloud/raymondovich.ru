# 2026-11-11 — Исправления экрана идеи и возврата в реестр

- Детальный экран использует нейтральный контейнер `.ideas-detail-content`, а не прежний `.ideas-detail`, на который распространялись карточные стили. Это исключает повторное применение карточной оболочки к содержимому идеи.
- Описание идеи принудительно отображается целиком: автоматическая высота, перенос длинных слов и строк, сохранение переводов строк; сняты ограничения обрезки.
- Краткое описание в строках реестра может занимать до двух строк вместо одной обрезанной строки.
- Повторное нажатие активной вкладки «Идеи» синхронно инициирует сброс экрана через отдельное событие модуля; `showRegistry()` напрямую возвращает реестр даже если маршрутизатор не публикует повторное состояние текущего маршрута.
- Изменения затрагивают только интерфейс и навигацию. Данные, права и backend не изменялись.
- Работа выполнена в тестовой ветке `ui/prototype-v3-full-parity` / PR #26. `main`, Production и Supabase не затрагивались.

## Проверки
- Статически проверены отсутствие карточного класса на контейнере подробностей, обработчик явного сброса в реестр и сохранение правил переноса описания.
- Build и визуальная проверка на iPhone Safari ещё не подтверждены.
