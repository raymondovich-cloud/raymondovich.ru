# Исправление активного пункта и выравнивания навигации

Дата: 05.11.2026

## Изменения
- Пункт HOME переименован в «Главная страница».
- Добавлена единая логика раскрывающихся разделов: одновременно может быть открыт только один блок.
- При открытии «Как стать партнёром» или FAQ активное выделение ссылки текущей страницы снимается, чтобы визуально активным оставался только раскрытый раздел.
- После закрытия раскрытого блока восстанавливается выделение ссылки текущей страницы.
- Верхние пункты навигации и summary раскрывающихся разделов выровнены по той же сетке, что и нижняя группа: одинаковая ширина колонки аббревиатуры, нулевые боковые смещения и единая высота строк.

## Архитектура
- `source/presentation/account/sidebar-navigation.js` — поведение раскрывающихся разделов и активного состояния.
- В HTML обновлены подпись HOME, подключение модуля и стили выравнивания.
