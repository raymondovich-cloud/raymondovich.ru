# Кнопка выхода из аккаунта

Дата: 05.11.2026

## Изменения
- В нижней части боковой панели после разделителя добавлена кнопка «Выйти».
- Кнопка размещена на главной странице, в каталоге продуктов, на странице форматов сотрудничества, в профиле и настройках.
- Выход реализован через Supabase Auth `supabase.auth.signOut()`.
- После успешного завершения сеанса пользователь перенаправляется на главную страницу `/`.
- При ошибке пользователь получает сообщение, кнопка снова становится доступной.

## Архитектура
- `source/application/account/account-session.js` — операция завершения пользовательского сеанса.
- `source/presentation/account/sidebar-logout.js` — обработчик кнопки боковой панели.
- В HTML добавлены только разметка кнопки, стили и подключение presentation-модуля.
