# Раздел «Настройки» и управление аккаунтом

- Под кнопкой «Профиль» добавлена кнопка «Настройки» с подписью «Профиль и безопасность» на всех публичных страницах с боковой навигацией.
- Создана отдельная страница `pages/settings/settings.html`.
- Страница разделена на блоки «Профиль» и «Безопасность».
- Реализовано управление именем, фамилией и часовым поясом через пользовательские метаданные Supabase Auth.
- Реализованы запрос на смену email с подтверждением нового адреса и смена пароля для активной сессии.
- Добавлены отдельные application- и presentation-модули.
- Страница требует авторизации; неавторизованному посетителю показывается переход ко входу.
