# Изменения — GitHub Read-only

**Дата:** 2026-11-13  
**Версия:** 1.0  
**Статус:** спецификация подготовлена; реализация не начата

## Добавлено

- Подготовлено ТЗ первого внешнего инструмента Raymondovich — GitHub Read-only.
- Зафиксирован исключительно read-only scope и запрет любых write-операций.
- Описаны GitHub App, минимальные permissions, установка, одноразовый state, callback, серверная выдача installation token, приватное хранение связей, webhook lifecycle, отвязка, тесты и критерии приёмки.
- Привязка репозиториев к проектам отложена до утверждения Projects/RBAC.

## Ограничения

- Миграции Supabase и Edge Functions не создавались.
- GitHub App не регистрировалось и не устанавливалось.
- Секреты и настройки Supabase не читались и не изменялись.
- UI и Tool Registry не изменялись.
