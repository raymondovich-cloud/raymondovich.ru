# Дополнительные параметры при создании идеи — 4.11.2026

## Интерфейс
- Основная форма быстрой фиксации идеи сохранена: название и краткое описание.
- Добавлена сворачиваемая секция «Дополнительные параметры».
- В секции доступны необязательные поля: цель проекта, примерные расходы в рублях и дополнительная информация.
- Секция по умолчанию закрыта и сбрасывается после успешного сохранения.

## Данные
- В public.ideas добавлены goal, estimated_cost и additional_info.
- При запуске идеи значения переносятся в соответствующие поля public.projects.
- Дополнительные параметры не обязательны; оценка расходов может оставаться пустой.
- Существующие RLS-политики и права доступа сохранены.
