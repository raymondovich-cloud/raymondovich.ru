# Центр управления: фундамент и быстрый сбор идей

Дата: 04.11.2026

## Что реализовано

- Административная оболочка переработана в адаптивный Control Center.
- Добавлена навигация «Обзор / Идеи / Проекты».
- Добавлена быстрая форма фиксации идеи: обязательное только название, описание — необязательно.
- Идеи и проекты используют одну запись в `public.projects`; запуск меняет статус, не создавая дубликат.
- Добавлены быстрые действия: приоритет, запуск, рассмотрение, пауза, завершение, архивирование и удаление.
- Добавлены счётчики идей, активных проектов и приоритетных направлений.
- Добавлена поддержка приоритета и целевых дат в модели проектов.
- Сохранены существующая авторизация, проверка admin-роли и выход из аккаунта.

## Архитектура

- UI остаётся в presentation.
- Операции с проектами вынесены в application/projects/project-service.js.
- Доступ к данным выполняется через существующий Supabase client.
- Действуют существующие RLS-политики таблицы projects; запросы дополнительно фильтруются по owner_id.
- Внешние AI-сервисы, пуши и командные роли не подключались.

## Ограничения этапа

- Статистика, карта готовности и документация проекта пока не реализованы.
- AI-помощник, ежедневные отчёты и Web Push пока не реализованы.
- Поддержка партнёрских ролей не реализована; доступ по-прежнему только для admin.
- Не добавлялись тестовые проекты или демонстрационные идеи.

## Проверка

- Схема Supabase расширена миграцией `extend_projects_for_idea_inbox`.
- После публикации требуется проверить создание, обновление статуса, приоритет и удаление через авторизованную сессию в Safari на iPhone.


## Дополнение 3.1

- Добавлен отдельный просмотр архива на странице проектов.
- Архивные записи можно вернуть в рабочий список или удалить окончательно.
- Уточнена подпись счётчика входящих идей.
