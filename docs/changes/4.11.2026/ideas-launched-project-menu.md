# Меню действий для идей, переданных в проекты — 4.11.2026

## Изменения
- Для идеи со статусом «Передана в проект» добавлен жест длительного нажатия (около 550 мс), открывающий отдельное модальное меню связанного проекта.
- Меню поддерживает закрепление/открепление, паузу/возобновление, изменение приоритета, завершение, архивацию и удаление проекта.
- Удаление проекта использует существующую логику: исходная идея возвращается на рассмотрение.
- Состояние закрепления хранится в существующем поле projects.is_pinned; обновление поля добавлено в project-service.
- Добавлена визуальная индикация закреплённого проекта.
- Обновлена версия интерфейса до 4.7.

## Проверка
- Проверены изменения исходного кода и сохранение существующих обработчиков действий.
- Не выполнена браузерная проверка на реальном устройстве; требуется проверить long-press в Safari на iPhone, открытие меню и выполнение каждого действия.
