# 4.11.2026 — Исправление увеличения при фокусе на полях ввода

- На мобильных экранах всем полям `input`, `textarea` и `select` задан минимальный размер текста 16 px.
- Это предотвращает автоматическое масштабирование страницы iOS Safari при фокусе на поле ввода.
- Изменение действует во всех разделах приложения и не отключает масштабирование страницы жестами, сохраняя доступность.
- Обновлена версия интерфейса и cache-busting ресурсов до 4.10.
- Проверены CSS-правило, версия HTML и ссылки на ресурсы. Физическое тестирование на iPhone не выполнялось.
