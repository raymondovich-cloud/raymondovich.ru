# Изменение главного экрана — 2026-11-06

## Что изменено

- Удалена статическая орбитальная композиция из hero главной страницы.
- Удалена ссылка «Форматы сотрудничества» рядом с основной кнопкой.
- Hero переведён на одноколоночную компоновку без пустого места под удалённую графику.
- Интерактивное знакомство с системой по кнопке «Знакомство с системой» сохранено.
- Орбитальная анимация остаётся внутри интерактивного диалога и использует ресурсы Motion System из Design System Core.

## Границы изменения

Не изменялись маршруты, содержимое отдельных страниц, сценарий интерактивного знакомства и его JavaScript-логика.
