- В Owner Control Center включён переход в Projects.
- Реализованы реестр существующих проектов, поиск, создание проекта напрямую и обзор проекта.

- Production Supabase DDL не менялся. До реализации новых таблиц потребуется staging-проверка, RLS, явные Data API grants и тесты доступа.

- Уточнена реализация изоляции: Services, Accounting, Analytics и Marketing вынесены в отдельные presentation entrypoints и отдельные application contracts.
- Добавлен Project Overview coordinator, который собирает сводки через публичные контракты модулей; presentation Projects не обращается напрямую к Supabase и не читает таблицы Services самостоятельно.
- Доступ к существующим таблицам Projects/Services инкапсулирован в Supabase repository adapter.

- После возврата из вложенного модуля обзор проекта перечитывает сводки, чтобы показывать актуальное число подключённых сервисов.

- Исправлена передача контекста владельца в Services при ручном добавлении сервиса; при возврате из модуля обзор проекта перечитывает актуальные сводки.

- Раздел Services дополнен самостоятельным управлением ресурсами и инфраструктурой: ручное создание доменов, репозиториев, баз данных, серверов, API, DNS-зон и развёртываний.
