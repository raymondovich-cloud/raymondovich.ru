# 2026-11-13 — Tool Registry implementation

## Реализовано
- Добавлен чистый доменный контракт инструмента: `source/domain/tools/tool-contract.js`.
- Добавлен неизменяемый реестр: `source/domain/tools/tool-registry.js`.
- Контракт проверяет стабильный slug, имя, описание, категорию, SemVer, видимость, доступность, capabilities, маршруты и ключ интеграции.
- Реестр отклоняет дублирующиеся ID, предоставляет поиск по ID и каталог с фильтрацией скрытых инструментов.
- Начальный production registry оставлен пустым: существующие каталоги vendor-интеграций не считаются автоматически утверждёнными пользовательскими инструментами.
- Добавлены автоматические тесты доменного контракта и реестра, а также отдельный GitHub Actions workflow.

## Границы этапа
- Supabase, миграции, grants, проектные подключения, UI и навигация не изменялись.
- Реестр не предоставляет пользователям доступ и не выполняет авторизацию; это следующий слой после утверждения продуктовых карточек инструментов.
- Runtime-результат тестов будет подтверждён GitHub Actions после запуска workflow на GitHub.
