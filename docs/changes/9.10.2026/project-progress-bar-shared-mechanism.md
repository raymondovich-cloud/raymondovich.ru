# Повторное исправление шкалы готовности в списке проектов

**Дата:** 09.10.2026  
**Время:** около 18:06 МСК

## Причина
Первое исправление включило заполнение отдельного элемента списка через CSS-переменную. Это не перенесло существующую механику из открытого проекта буквально, поэтому визуально проблема сохранилась.

## Решение
Список проектов теперь использует ту же механику, что и открытый проект:
- тот же `calculateProgress(project)` для расчёта процента;
- тот же класс `project-progress-track`;
- тот же дочерний `span` с inline-шириной `width: N%`;
- те же правила CSS, которые окрашивают заполненную часть в акцентный цвет.

Удалена отдельная реализация заполнения шкалы списка, чтобы два места не расходились по логике.
