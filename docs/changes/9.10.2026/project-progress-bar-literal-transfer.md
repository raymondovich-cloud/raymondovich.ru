# Буквальный перенос механики шкалы готовности в список проектов
Версия 1.0

Дата: 09.10.2026

## Решение
Предыдущие исправления оставляли для общего списка отдельную структуру шкалы. Теперь шкала внутри каждой строки списка формируется той же функцией `progressHtml(progress)`, которая уже используется в открытом проекте. Таким образом, обе области используют один и тот же DOM-шаблон: `.project-progress`, `.project-progress-track`, заполняющий `span` с inline-шириной и процент справа.

Отдельная реализация полосы для списка удалена. В списке сохранена подпись «Готовность», а общая шкала и процент отображаются общей механикой.

## Изменённые файлы
- `source/presentation/projects/projects-page.js` — версия 2.5; список использует `progressHtml(progress)`.
- `source/design/projects.css` — версия 2.3; размеры общей шкалы адаптированы для компактного списка без изменения правил шкалы открытого проекта.
- `projects.html` — версия страницы и параметры кэширования обновлены до JS 2.5 и CSS 2.3.

## Проверка
- Перед изменением проверено точное совпадение старого блока списка; изменение выполняется только при совпадении ожидаемой разметки.
- После публикации требуется подтвердить визуальное поведение в Safari. Успешная сборка сама по себе не доказывает, что браузер показывает корректное заполнение.
