# Переработка интерфейса раздела «Инструменты»

**Дата:** 09.10.2026

## Что изменено

- Первый экран упрощён: общая статистика и список сервисов остаются видимыми, детали сервиса скрыты до выбора.
- При выборе сервиса открывается его обзор с ресурсами и связями в отдельных сворачиваемых секциях.
- Для REG.RU при выборе сервиса автоматически раскрывается секция «Домены и DNS».
- Название ресурсной секции адаптируется к категории сервиса: домены и DNS, проекты баз данных и ресурсы либо общий список ресурсов.
- Редактирование сервиса, добавление сервиса и управление ресурсами объединены под сворачиваемым разделом «Управление сервисами и ресурсами».
- Создание связей и полный список связей перенесены в отдельный сворачиваемый раздел «Управление связями и полный реестр».
- Исправлены действия редактирования: нужная панель управления автоматически раскрывается перед прокруткой к форме.
- На мобильных устройствах после выбора сервиса интерфейс плавно прокручивается к его деталям.
- Структура базы данных и политики безопасности не менялись.

## Проверка

- Версии интерфейса обновлены до 1.5; query-параметр JavaScript обновлён для сброса кэша.
- Требуется реальная браузерная проверка опубликованной страницы, включая мобильный экран, раскрытие разделов и все операции CRUD.
