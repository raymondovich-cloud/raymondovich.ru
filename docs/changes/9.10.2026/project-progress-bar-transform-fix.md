# Исправление заполнения шкалы в списке проектов

Дата: 09.10.2026
Время: около 18:36 МСК

## Изменение
В списке проектов заливка шкалы теперь использует элемент шириной 100% и CSS-трансформацию `scaleX(progress / 100)` с точкой начала слева. Это позволяет визуально отображать заполнение от 0 до 100%, не полагаясь на вычисление ширины самого дочернего элемента. Значение ограничивается диапазоном 0–100.
