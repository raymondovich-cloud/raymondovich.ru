# Увеличена длительность удержания для меню проекта
Версия 1.0

Дата: 09.10.2026

## Изменение
В `source/presentation/projects/projects-page.js` порог открытия контекстного меню проекта увеличен с 550 мс до 800 мс. Теперь меню требует более осознанного удержания пальца/кнопки; обычное короткое нажатие по-прежнему открывает проект.

Версия JavaScript повышена до 3.0, ссылка на ресурс в `projects.html` обновлена для обхода кэша.

## Проверки
Проверить после коммита:
- значение порога равно 800 мс;
- короткое нажатие продолжает открывать проект;
- меню открывается только после истечения таймера удержания;
- JavaScript загружается по новому cache-busting URL.
