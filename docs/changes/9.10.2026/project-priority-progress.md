# Приоритет проектов и шкала готовности

**Дата:** 09.10.2026

## Что изменено

- Добавлено закрепление проекта через долгое нажатие на его строку в разделе «Проекты».
- Закреплённые проекты отображаются выше остальных; порядок между закреплёнными сохраняется в базе данных.
- В меню проекта добавлены действия «Закрепить проект» и «Открепить проект».
- В списке проектов появилась шкала готовности и процент.
- Готовность вычисляется на основании весов этапов и завершённых задач карты проекта; отдельное ручное значение процента не хранится.
- Список проектов получает этапы и задачи одним набором запросов и использует тот же расчёт, что и экран подробностей.
- В таблицу `projects` добавлены поля `is_pinned` и `pin_order`; существующие RLS-политики не изменялись.
- Обновлены версии файлов и cache-busting параметры интерфейса.

## Проверка

- Миграция Supabase применена: `20261009143602_add_project_pinning`.
- Схема проверена через Supabase: оба поля присутствуют, RLS для `projects` включён.
- Статическая проверка синтаксиса обоих JavaScript-модулей пройдена; HTML содержит согласованные script-теги и обновлённые cache-busting параметры.
- Security Advisor не показал новых проблем от этой миграции; остаётся ранее существовавшее предупреждение Supabase Auth о выключенной защите от скомпрометированных паролей.
- Требуется ручная проверка опубликованной страницы на iPhone: закрепить/открепить несколько проектов, обновить страницу и проверить изменение процента после отметки задачи.


## Уточнение визуализации шкалы — 09.10.2026

- Заполнение шкалы теперь использует отдельный класс и CSS-переменную с текущим процентом готовности.
- Добавлены контрастный оранжевый градиент, более заметная дорожка и анимация заполнения от 0 до актуального значения.
- Добавлены новые версии CSS/JS и обновлены cache-busting параметры, чтобы браузер загрузил изменения.
- Проверка синтаксиса и фактическое отображение в браузере должны быть подтверждены после публикации.


## Исправление заполнения шкалы в списке — 09.10.2026

- Убрана CSS-переменная и анимация ключевых кадров из расчёта ширины заполнения: на шкале списка ширина теперь задаётся непосредственно inline-значением `width: N%`, рассчитанным из процента проекта.
- Сохранён плавный переход при изменении ширины через `transition: width`.
- Обновлены версии JS/CSS/HTML и параметры кеширования.
- Причина подтверждена по коду: в подробной карточке ширина задавалась напрямую, а в списке использовалась CSS-переменная вместе с keyframes-анимацией. Это устранено для совместимости с Safari.


## Усиление совместимости шкалы со списком Safari — 09.10.2026

- Заполнение шкалы списка перенесено непосредственно в фон дорожки через `linear-gradient`, где граница заполнения задаётся текущим процентом проекта.
- Это исключает зависимость видимости заполнения от отображения дочернего `span` внутри кнопки в Safari.
- Обновлены версии CSS/JS/HTML и параметры кеширования.
- После публикации требуется повторная визуальная проверка в Safari.
