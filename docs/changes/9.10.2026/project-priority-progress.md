# Приоритет проектов и шкала готовности

**Дата:** 09.10.2026

## Что изменено

- Добавлено закрепление проекта через долгое нажатие на его строку в разделе «Проекты».
- Закреплённые проекты отображаются выше остальных; порядок между закреплёнными сохраняется в базе данных.
- В меню проекта добавлены действия «Закрепить проект» и «Открепить проект».
- В списке проектов появилась шкала готовности и процент.
- Готовность вычисляется на основании весов этапов и завершённых задач карты проекта; отдельное ручное значение процента не хранится.
- Список проектов получает этапы и задачи одним набором запросов и использует тот же расчёт, что и экран подробностей.
- В таблицу `projects` добавлены поля `is_pinned` и `pin_order`; существующие RLS-политики не изменялись.
- Обновлены версии файлов и cache-busting параметры интерфейса.

## Проверка

- Миграция Supabase применена: `20261009143602_add_project_pinning`.
- Схема проверена через Supabase: оба поля присутствуют, RLS для `projects` включён.
- Статическая проверка синтаксиса обоих JavaScript-модулей пройдена; HTML содержит согласованные script-теги и обновлённые cache-busting параметры.
- Security Advisor не показал новых проблем от этой миграции; остаётся ранее существовавшее предупреждение Supabase Auth о выключенной защите от скомпрометированных паролей.
- Требуется ручная проверка опубликованной страницы на iPhone: закрепить/открепить несколько проектов, обновить страницу и проверить изменение процента после отметки задачи.
