# Исправление кэширования шкалы готовности в списке проектов
Версия 1.0

Дата: 09.10.2026

## Причина
После переноса списка проектов на общий механизм шкалы в `projects-page.js` версия JS-файла была изменена на 2.4, но в `projects.html` оставалась ссылка с параметром кэширования `projects-page.js?v=2.3`. Safari мог продолжать использовать старый JS, который создавал прежнюю разметку шкалы, тогда как CSS уже был обновлён и прежний CSS-селектор удалён. Это объясняет, почему предыдущие правки не проявлялись.

## Исправление
- Обновлена ссылка на скрипт в `projects.html`: `v=2.3` → `v=2.4`.
- Логика и стили шкалы не менялись повторно: исправлена версия ресурса, которую загружает браузер.

## Проверка
- Код репозитория содержит новую ссылку `projects-page.js?v=2.4`.
- Требуется проверить опубликованную страницу в Safari после завершения GitHub Pages deployment. Если Safari продолжит показывать старый вариант, открыть страницу в частном доступе и проверить адрес загруженного JS.
