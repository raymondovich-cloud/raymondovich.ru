# Удаление отдельной механики шкалы в общем списке проектов
Версия 1.0

Дата: 09.10.2026

## Решение
Полностью удалена самостоятельная HTML/CSS-механика заполнения шкалы из общего списка проектов. Список теперь вызывает ту же функцию `progressHtml(progress)`, что и открытая карта проекта. Оба состояния используют идентичную структуру DOM и общий CSS для трека и заполненной части; различается только компактное оформление компонента в строке списка.

Удалены прежние inline-стили, отдельная разметка трека и трансформация `scaleX`, применявшиеся только в списке.

## Изменённые файлы
- `source/presentation/projects/projects-page.js` — версия 2.8.
- `source/design/projects.css` — версия 2.6.
- `projects.html` — версия 2.8; обновлены параметры кэширования ресурсов.

## Проверка
Повторно прочитать файлы после записи и убедиться, что список вызывает `progressHtml(progress)`, а отдельная разметка трека больше не используется. Визуальную работу опубликованной страницы необходимо подтвердить в браузере после деплоя.
