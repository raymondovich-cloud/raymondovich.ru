# Изменения Projects — 9.10.2026

## Изменено
- Убрана постоянно отображаемая кнопка «Удалить» у активных проектов.
- Обычное нажатие на проект открывает проект.
- Длительное нажатие на проект открывает контекстное окно действий.
- В окне показывается информация: когда и кем проект добавлен.
- Добавлено действие «Изменить» для редактирования названия проекта.
- Добавлено действие «Удалить» с подтверждением.
- Для длительного нажатия добавлена тактильная обратная связь на поддерживаемых устройствах.
- Контекстное окно появляется внутри списка под выбранным проектом.

## Изменённые файлы
- `source/application/projects/project-service.js` — version 1.4.
- `source/presentation/projects/projects-page.js` — version 1.8.
- `source/design/projects.css` — version 1.5.
- `projects.html` — version 1.6.

## Результат
Активные проекты больше не имеют постоянно видимой кнопки удаления. Управление проектом вынесено в меню, вызываемое длительным нажатием.
