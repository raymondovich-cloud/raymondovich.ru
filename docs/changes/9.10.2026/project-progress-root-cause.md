# Исправление шкалы готовности в списке проектов
Версия 1.1

Дата: 09.10.2026

## Причина
В разметке строки проекта открывался тег `<strong>` вокруг названия, но закрывающий `</strong>` отсутствовал до закрытия контейнера заголовка. Из-за этого браузер разбирал последующую разметку списка в некорректной структуре DOM. Предыдущие изменения меняли оформление шкалы, но не устраняли дефект исходной HTML-разметки.

## Исправление
- Закрыт тег названия проекта до бейджа и последующих элементов строки.
- Список и детальная карточка по-прежнему используют одну функцию `progressHtml(progress)`.
- Общая заполненная часть шкалы получила явный класс `project-progress-fill`; ширина задаётся через CSS-переменную `--progress`, а общий стиль явно задаёт оранжевый цвет заполнения.
- Процент ограничивается диапазоном 0–100 и округляется перед отображением.
- Обновлены версии JS/CSS и ключи кэша страницы.

## Дополнительная защита от устаревшей HTML-страницы
Предыдущие правки меняли query-параметры CSS/JS, но сам URL документа `projects.html` оставался неизменным. Добавлен единый параметр выпуска `release=20261009-1549` при переходе из панели администратора в список проектов и обратно. Переход после создания проекта также сохраняет параметр вместе с `project`. Версионированы навигационный модуль и HTML-страницы, чтобы браузер не продолжал использовать ранее закэшированный документ со старыми адресами ресурсов.

## Проверки
Проверено содержимое файлов в `main`: корректная разметка названия, единый компонент шкалы для списка и детали, общий CSS-класс заполнения, корректные версии ресурсов и cache-busting для URL документа. Проверка JavaScript на синтаксис пройдена. Отдельный тестовый рендер в Chromium для значений 0%, 25%, 50% и 100% показал ожидаемую ширину заполнения и оранжевый цвет. GitHub Pages deployment для исправления завершился успешно. Визуальную проверку именно в Safari пользователя нельзя заявлять выполненной из этой среды.
