# Принудительное отображение заполнения шкалы в общем списке
Версия 1.0

Дата: 09.10.2026

## Причина дальнейшего исправления
Перенос общей разметки шкалы не устранил визуальный дефект в общем списке. Поэтому для списка устранена зависимость от потенциальных конфликтов CSS: ширина трека и отображение/цвет заполненной части теперь явно заданы непосредственно на элементах шкалы. Реализация шкалы внутри открытого проекта не изменена.

## Изменения
- `source/presentation/projects/projects-page.js` — версия 2.6. В списке сохранён расчёт `calculateProgress(p)`; заливка получает явные inline-значения `display:block`, `width:N%`, `height:100%` и цвет.
- `source/design/projects.css` — версия 2.4. Уточнена геометрия трека списка: фиксированная доступная ширина и запрет сжатия.
- `projects.html` — версия 2.6; обновлены параметры кэширования JS/CSS.

## Проверка
Код повторно читается из GitHub после записи. Сборка и публикация проверяются отдельно. Визуальный результат нельзя считать подтверждённым без проверки фактической страницы в браузере.
