# Исправление шкалы готовности в общем списке проектов

**Дата:** 09.10.2026  
**Время:** около 18:00 МСК

## Причина
В `source/presentation/projects/projects-page.js` шкала уже получала процент через CSS-переменную `--progress-width`, но в `source/design/projects.css` для элемента заполнения было задано `display: none`. Поэтому процент и ARIA-значение отображались, а сама полоса оставалась серой.

## Изменения
- `source/design/projects.css`: версия 2.1. Удалено скрытие заполнения; полоса теперь отображается, получает ширину из `--progress-width` и использует акцентный цвет.
- `projects.html`: обновлён параметр версии CSS до `v=2.1`, чтобы браузер не использовал закэшированную таблицу стилей.

## Проверка
- Причина подтверждена чтением кода: HTML передавал процент, CSS принудительно скрывал заливку.
- Изменения сохранены в основной ветке `main`.
- Требуется проверить опубликованную страницу после завершения GitHub Pages deployment. Визуальную проверку в Safari из этой среды выполнить невозможно.

## Следующий шаг
Открыть `raymondovich.ru/projects.html` после публикации и проверить проекты с разными процентами готовности.
