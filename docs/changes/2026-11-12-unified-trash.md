# Единая корзина проектов и идей — 2026-11-12

## Реализовано в feature/unified-trash-2026-11-12

- Добавлена единая точка входа «Профиль → Разработка → Корзина».
- Создан отдельный экран общей корзины с фильтрами «Все», «Проекты», «Идеи».
- Для каждой записи отображаются название, тип и дата перемещения в корзину.
- Добавлены действия восстановления и безвозвратного удаления с подтверждением.
- Убрана отдельная кнопка и навигационный экран корзины из реестра проектов.
- В детали идеи добавлено отдельное действие «Переместить в корзину». Архивирование осталось самостоятельной операцией.
- Активный реестр идей исключает записи с `deleted_at IS NOT NULL`.
- Для идей добавлено поле `deleted_at`; восстановление не изменяет `status` и `archived_at`, поэтому прежнее состояние архива сохраняется.
- Добавлены события истории `moved_to_trash` и `restored_from_trash`.
- Безвозвратное удаление идеи разрешено RLS только после перемещения в корзину.

## Целостность данных

- `idea_activity.idea_id` использует `ON DELETE CASCADE`: при окончательном удалении идеи её история активности удаляется вместе с ней.
- `projects.source_idea_id` использует `ON DELETE SET NULL`: окончательное удаление исходной идеи не удаляет созданный из неё проект, но снимает ссылку на идею.
- Восстановление идеи сохраняет её исходные `status` и `archived_at`.
- Операции выполняются через обычную пользовательскую сессию Supabase и ограничиваются RLS; сервисный ключ не используется.

## Ограничения проверки

- Миграция создана в репозитории, но не применялась к Supabase.
- Production-база, секреты и пользовательские данные не изменялись.
- Проверена структура исходного кода и маршрутов через GitHub API. Полноценный запуск браузера, E2E и выполнение SQL в Supabase в этой сессии не проводились.
- Перед тестированием в Preview необходимо применить новую миграцию к отдельной тестовой базе и проверить сценарии soft-delete, восстановления, hard-delete, архивной идеи и преобразованной идеи.


## Исправление перемещения проектов в корзину — 2026-11-12

- В обработчик кликов реестра проектов добавлено действие для кнопки «Переместить в корзину».
- Перед перемещением показывается подтверждение с названием проекта.
- После подтверждения вызывается существующая операция `moveProjectToTrashRecord()`; при успехе кэш проектов инвалидируется, список перезагружается, пользователь возвращается в реестр.
- Ошибки операции показываются пользователю; кнопка повторно активируется, если перемещение не удалось.
- Проверка браузерного сценария после публикации не проводилась в рамках этой операции.


## Повторное исправление обработчика кнопки проекта — 2026-11-12
