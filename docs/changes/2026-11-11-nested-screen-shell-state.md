# Синхронизация оболочки с вложенной навигацией

## Симптом
На вложенных экранах идей и проектов интерфейс визуально сохранял состояние корневого раздела. Проблема проявлялась одинаково в разных модулях: идея, карточка проекта и его сервисы/бухгалтерия.

## Причина в коде
Роутер хранит вложенный экран отдельно от маршрута раздела: например, `route=#authorization/projects` и `screen=project-overview`. Оболочка ранее определяла глубину навигации только по `route`. Поэтому переходы внутри Ideas и Projects не переключали `is-push-screen`, не обновляли верхнюю панель и не скрывали нижнюю навигацию, хотя модуль уже показывал вложенный экран.

## Исправление
- Добавлено определение вложенного состояния по паре `route + screen`.
- Оболочка синхронизирует `is-push-screen`, кнопку «Назад», состояние нижней навигации и заголовок при каждом событии `raymondovich:navigation`.
- Корневые экраны `projects-registry` и `ideas-registry` сохраняют обычное состояние.
- При первой отрисовке используется то же определение глубины навигации, поэтому прямое открытие/восстановление вложенного состояния обрабатывается согласованно.

## Проверки
- Проверена логика имен экранов Ideas: `ideas-registry`, `idea-detail`, `idea-form`.
- Проверена логика Projects: `projects-registry`, `project-overview`, `project-services`, `project-accounting`, `project-analytics`, `project-marketing`, `project-create`.
- Статическая проверка кода и реальная проверка на iPhone Safari должны быть завершены до признания дефекта устранённым.

## Ограничения
Изменение затрагивает только клиентскую оболочку в тестовой ветке. Production, `main` и Supabase не изменялись.
