## 3. Состав зафиксированного состояния

В PR #26 объединены утверждённые изменения интерфейса авторизованного пространства и навигации, в том числе:

- Profile и Settings приведены к утверждённой композиции UI prototype v3.
- Обновлена структура Owner Control Center.
- Обновлены Ideas и Projects: заголовки, поиск, фильтры, статистика, карточки и вложенные представления.
- Authenticated App Shell использует полноэкранную геометрию, верхнюю панель, навигацию и корректное поведение вложенных маршрутов.
- Исправлено сохранение `body[data-page="authenticated-workspace"]` при навигации внутри уже смонтированной авторизованной оболочки.
- Стили остаются в Design System; CSS-in-JS и inline styles в рамках принятого подхода не вводились.

### PIN и безопасность

- PIN UI остаётся отключённым. Его восстановление — отдельная будущая задача.
- Пять main-only PIN-коммитов не переносились как изменения содержимого итогового дерева. Merge history содержит main как второго родителя синхронизирующего merge-коммита, но итоговое дерево feature было сохранено без восстановления PIN UI.
- Supabase Auth, роли, RLS, Edge Function `pin-auth`, таблицы и PIN-данные в ходе этой операции не изменялись.
- Не считать PIN-функциональность реализованной или проверенной этим baseline.
