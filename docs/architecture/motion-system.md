# Raymondovich — Motion System

**Версия:** 1.1  
**Дата:** 2026-11-06  
**Статус:** базовые motion-токены и foundation реализованы; сценарий презентации экосистемы подключён к публичной главной странице.

## 1. Назначение

Motion System — часть Design System Core. Она задаёт единые правила времени, easing, амплитуды и доступности анимаций во всех пользовательских пространствах Raymondovich.ru.

Анимация не является самостоятельным украшением. Она должна объяснять изменение состояния, показывать связь элементов, поддерживать иерархию или помогать пользователю ориентироваться.

## 2. Принципы

1. **Purposeful motion:** каждое движение имеет функциональную причину.
2. **Consistency:** одинаковые типы переходов используют общие токены длительности и easing.
3. **Hierarchy:** движение не должно конкурировать с основным содержимым.
4. **User control:** последовательные презентации управляются пользователем; автопереходы между смысловыми шагами не используются.
5. **Performance:** преимущественно анимируются opacity, transform, rotate и другие свойства, не вызывающие тяжёлую переразметку.
6. **Responsive:** композиция и длительности проверяются на мобильных и широких экранах.
7. **Accessibility:** при `prefers-reduced-motion: reduce` движение сокращается до практически незаметных переходов; смысл и доступ к содержимому сохраняются.

## 3. Канонические motion-токены

Источник: `source/design/tokens/motion.css`.

| Токен | Назначение |
|---|---|
| `--motion-duration-instant` | короткая реакция интерфейса |
| `--motion-duration-fast` | быстрый микропереход |
| `--motion-duration-standard` | стандартный переход компонента |
| `--motion-duration-slow` | акцентное появление или раскрытие |
| `--motion-duration-orbit` | полный оборот внешней орбиты за 90 секунд |
| `--motion-duration-orbit-reverse` | полный обратный оборот внутренней орбиты за 110 секунд |
| `--motion-ease-standard` | стандартная кривая перехода |
| `--motion-ease-enter` | появление элемента |
| `--motion-ease-exit` | уход элемента |
| `--motion-distance-subtle` | небольшое смещение при появлении |

Новые интерфейсы должны использовать эти токены вместо произвольных значений, если сценарий соответствует их назначению. Новые motion-токены добавляются только при подтверждённой повторяющейся потребности.

## 4. Motion Foundation

Файл: `source/design/foundations/motion.css`.

Foundation обеспечивает общую обработку системного предпочтения reduced motion. Уменьшение движения не должно скрывать состояние, блокировать сценарий или менять бизнес-результат.

Для каждой анимации требуется проверить:
- состояние до начала движения;
- состояние после завершения;
- поведение при reduced motion;
- отсутствие зависимости от hover;
- корректность на сенсорном экране;
- отсутствие непрерывного движения без функциональной необходимости.

## 5. Паттерн: Ecosystem Presentation

Файл: `source/design/patterns/orbital-introduction.css`.

Паттерн — управляемая 45-секундная презентация публичной экосистемы, запускаемая кнопкой «Знакомство с системой». Сценарий раскрывается по временной шкале:

| Время | Содержание |
|---|---|
| 0–3 с | Тёмное поле с тонкой точечной сеткой |
| 3–6 с | Центральный бренд RAYMONDOVICH и подпись «Цифровая экосистема» |
| 6–12 с | Четыре направления; система управления выделена оранжевым акцентом |
| 12–20 с | Внешняя орбита собственных продуктов: LIFE GAME и AI-SISTEM с указанными статусами |
| 20–30 с | Раскрытие четырёх модулей системы управления: бухгалтерия, подключённые сервисы, маркетинг и статистика |
| 30–36 с | Акцент на партнёрском направлении и условиях участия |
| 36–41 с | Связь системы управления с кабинетом RAYMONDOVICH `PRIVATE` |
| 41–45 с | Общий план экосистемы и CTA «Обсудить партнёрство» |

Внешняя орбита вращается за 90 секунд, внутренняя — в обратную сторону за 110 секунд. Появление продуктовых узлов и четырёх модулей разведено по времени. Временная шкала не зависит от количества кадров и управляется JavaScript через состояния сцены.

Управление:
- автоматический запуск при открытии презентации;
- пауза и продолжение;
- перезапуск с начала;
- пропуск к финальному CTA;
- закрытие кнопкой и клавишей Escape;
- при закрытии таймер останавливается.

Презентация использует нативный HTML `dialog`, CSS и vanilla JavaScript. Визуальная схема скрыта от скринридера; текстовое описание текущего этапа выводится отдельно.
## 6. Требования доступности

- Нативный диалог открывается модально и закрывается клавишей Escape.
- Управление доступно с клавиатуры и касанием.
- Кнопки имеют явные подписи и видимый focus.
- Изменение шага объявляется через live region.
- Прогресс представлен семантическим progressbar.
- Визуальная орбитальная схема скрыта от скринридера; смысл шага представлен текстом.
- Системное предпочтение reduced motion учитывается глобальным foundation.

## 7. Границы текущей реализации

Реализован базовый набор motion-токенов, reduced-motion foundation и паттерн знакомства с системой на Public homepage.

Это не означает, что все анимации платформы уже переведены на Motion System. Новые и существующие сценарии подключаются по мере их пересмотра и унификации. Общие значения motion остаются в Design System Core; бизнес-модули не должны заводить собственные конкурирующие шкалы.
