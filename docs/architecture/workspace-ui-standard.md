# Единый UI-стандарт Owner Control Center

> Версия: 1.0  
> Статус: На утверждении  
> Дата: 2026-11-10

## Назначение

Документ определяет общий визуальный и структурный стандарт реестров и экранов Owner Control Center. Эталонная анатомия — реестр «Идеи». Реестры «Идеи» и «Проекты» используют один набор паттернов Design System.

## Анатомия реестра

1. **Toolbar:** поле поиска и две кнопки действий — фильтры и создание.
2. **Фильтры:** скрытая по умолчанию панель; три колонки на широком экране и одна колонка на мобильном.
3. **Сводка:** необязательный блок с двумя stat-карточками (вторая акцентная) и карточкой-итогом с индикатором прогресса.
4. **Контент:** заголовок «В ФОКУСЕ», приглушённый заголовок «ОСТАЛЬНЫЕ», карточки и аккордеоны.

В реестре нет eyebrow, видимого h1, описания или отдельной строки количества. Для доступности присутствует ровно один h1 с классом `.ws-visually-hidden`.

Подэкраны используют общий `.ws-screen-head`: заголовок h1 и необязательный однострочный subtitle. Eyebrow и локальная кнопка возврата не добавляются; глобальная навигация назад остаётся единственной.

## Геометрия и адаптивность

| Элемент | Desktop | До 700 px | До 390 px |
|---|---:|---:|---:|
| Search | 84 px, radius 25 px | 48 px, radius 14 px | 45 px |
| Action buttons | 86 × 84 px | 48 × 48 px | 44 × 45 px |

Карточки, радиусы и вертикальный ритм согласуются с эталонным реестром идей. Контрольные ширины: 320, 375, 390, 700, 768, 1100 и 1440 px.

## Семантические токены

Общий workspace CSS использует только `--ws-*` токены. Значения тёмной темы определяются в `tokens/tokens.css`, светлой — в `themes/themes.css`. Акцент светлой темы — `#d65b1f`. Hex-значения не размещаются в общих паттернах.

## Классы Design System

`ws-page`, `ws-toolbar`, `ws-search`, `ws-toolbar-actions`, `ws-icon-button`, `is-accent`, `ws-filters`, `ws-overview`, `ws-stat-grid`, `ws-stat`, `ws-summary`, `ws-progress`, `ws-section-title`, `is-muted`, `ws-card-list`, `ws-card`, `is-focused`, `is-compact`, `ws-group`, `ws-empty`, `ws-screen-head`, `ws-visually-hidden`.

## JavaScript API

Модуль `source/presentation/public/scripts/shared/workspace-ui.js` предоставляет:

- `workspaceToolbar({...})`
- `workspaceFilters({...})`
- `workspaceStatGrid([...])`
- `workspaceSectionTitle(text, { muted })`
- `workspaceScreenHead({ title, subtitle })`
- `workspacePageTitle(text)`
- `escapeHtml(value)`

Функции возвращают HTML-строки и не управляют DOM, стилями или навигацией. Существующие `data-*` контракты и обработчики событий сохраняются.

## Обязательное правило

Каждый новый раздел Owner Control Center собирается из этого набора паттернов. Новые визуальные правила добавляются в Design System, а не в модули, HTML или JavaScript.

## Доступность и качество

- Видимый фокус обязателен для интерактивных элементов.
- Клавиатурная навигация и семантика ARIA сохраняются.
- Учитывается `prefers-reduced-motion`.
- Поля ввода не уменьшаются ниже 16 px.
- Нельзя использовать inline styles, `<style>`, `element.style` или визуальные hex вне файлов токенов и тем.
- Реестры должны корректно работать на всех контрольных ширинах без горизонтальной прокрутки.

## Этап внедрения

Версия 1.0 фиксирует общий контракт и базовые паттерны. Миграция реестров и экранов выполняется без изменения схемы БД, RLS, application layer, маршрутов и бизнес-поведения. До завершения миграции старые селекторы могут временно сосуществовать с общими классами.
