# Управление проектами

<!-- version 1.0 -->

## Назначение

Контур Projects хранит проекты владельца Raymondovich и определяет их готовность от 0 до 100%.

## Модель

- Project — идея, цель и критерии 100%.
- Milestone — измеримый этап с весом в общей шкале.
- Task — проверяемая задача внутри этапа.
- History — журнал событий.

## Расчёт

Прогресс проекта считается из milestones и tasks. Сумма весов milestones должна быть 100. Вклад этапа равен его весу, умноженному на долю выполненных task weights.

Процент не хранится как источник истины и не изменяется вручную.

## AI

ChatGPT получает структурированный запрос по идее и цели проекта и возвращает JSON-план. Raymondovich импортирует план после проверки. AI не имеет прямого права изменять прогресс.

## Безопасность

Все таблицы Projects защищены RLS. Доступ разрешён только authenticated admin с совпадающим owner_id.
