## 1. Назначение

Документ фиксирует поведение и границы авторизованной оболочки Raymondovich.ru. Публичная страница и формы входа/регистрации остаются отдельными интерфейсами. После успешной авторизации пользователь проходит приветственный экран и попадает в рабочую оболочку с нижней навигацией.

## 2. Состав оболочки

Нижние вкладки в фиксированном порядке:
1. Проекты;
2. Идеи;
3. Инструменты;
4. Профиль.

Панель использует safe-area браузера и Telegram WebApp, не перекрывает содержимое, скрывается при PIN-блокировке и полноэкранных формах. Верхняя публичная навигация скрывается внутри авторизованного интерфейса, но общий контрол возврата сохраняется.

Инструменты на текущем этапе — заглушка «В разработке». Заглушка не должна создавать впечатление доступной интеграции.

## 3. Навигация

Единственный источник истории — `window.RaymondovichNavigation`:
- вкладки и профильные разделы используют `navigateRoute`;
- вложенные экраны Projects/Ideas продолжают использовать `navigateScreen`;
- кнопка возврата использует общий контроллер;
- UI не создаёт независимую историю.

Маршруты описаны в `docs/architecture/navigation-history-architecture.md`.

## 4. Профиль и источники данных

Роль читается только из `user.app_metadata.role`. Клиентские значения из `user_metadata` не определяют полномочия.

| Поле | Источник |
|---|---|
| Роль | `app_metadata.role` |
| Имя | `user_metadata.display_name`, затем `full_name`, затем локальная часть e-mail |
| Аватар | `user_metadata.avatar_url` или `picture`, если URL валиден |
| E-mail | Supabase Auth user |
| Счётчик проектов | Application contract `getProjectsSummary()`, только в разрешённом контексте |
| Control Center | Только при `app_metadata.role === "admin"` |

Если источник отсутствует или недоступен, интерфейс показывает пустое/недоступное состояние, а не выдуманные данные.

Избранное и отчёты пока не имеют подключённого источника данных. Экран избранного показывает пустое состояние. Экран отчётов не показывает фиктивные отчёты или счётчики.

Управление модулями — только каркас со статусом «Скоро». Тарифы, цены, платежи и расчёт подписки не входят в текущую реализацию.

## 5. Права доступа

Текущая архитектурная граница Projects — admin-only. До отдельного утверждённого изменения серверных правил интерфейс не расширяет доступ партнёрам, ученикам или пользователям. Для ролей без разрешения показывается честное состояние «Нет доступа».

Owner Control Center отображается только для `app_metadata.role === "admin"`. Скрытие ссылки — только UI-ограничение; фактическая защита остаётся за существующей авторизацией и RLS. Схема БД, policies и серверные полномочия в этой задаче не меняются.

## 6. Изменение данных аккаунта

Presentation вызывает application use cases:
- `changeProfileEmail`;
- `changeProfilePassword`.

Application Layer использует Supabase Auth adapter в Infrastructure. Изменение e-mail требует прохождения штатного подтверждения адреса Supabase Auth. Пароль проверяется на минимальную длину и совпадение подтверждения.

PIN не реализуется повторно. Интерфейс вызывает существующий `RaymondovichPinGuard.changePin()`; блокировка и проверка PIN остаются в текущем механизме.

## 7. Design System

Визуальные правила находятся только в `source/design-system/`:
- `patterns/app-shell.css`;
- `patterns/profile.css`;
- семантические токены в `tokens/tokens.css`;
- значения светлой темы в `themes/themes.css`.

JavaScript управляет маршрутами, классами, data- и ARIA-атрибутами. Inline CSS, `element.style`, `setProperty` и новые зависимости не используются. Все поля ввода имеют размер шрифта не менее 16px. Анимации отключаются при `prefers-reduced-motion: reduce`.

## 8. Ограничения текущей версии

- Избранное не сохраняется: соответствующая модель данных пока отсутствует.
- Отчёты не подключены.
- Инструменты не реализованы.
- Управление модулями не подключено к подпискам или оплате.
- Счётчик проектов доступен только при наличии разрешения на чтение Projects.
- Визуальная и браузерная проверка должна быть выполнена в staging на iPhone Safari, Telegram Mini App и desktop перед публикацией.
